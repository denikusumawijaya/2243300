Spiral Review Warm-up

Pemanasan Tinjauan Ulang Spiral (00:00 - 00:10)

10 min

Key Mathematical Concepts / Konsep Kunci Matematika:

Before substituting numbers into algebraic expressions, we must master fundamental order of operations (**BIDMAS/BODMAS**) and sign rules:

Sebelum melakukan substitusi angka ke dalam ekspresi aljabar, kita harus menguasai urutan operasi dasar (BIDMAS/BODMAS) dan aturan tanda:

  • Brackets (Tanda Kurung): Calculate expressions inside brackets first / Hitung dalam kurung terlebih dahulu.
  • Indices/Exponents (Eksponen): Calculate powers like $a^2$ or $(-3)^2$ next / Hitung pangkat seperti $a^2$ atau $(-3)^2$.
  • Negative Numbers Rules (Aturan Bilangan Negatif): $(-)\times(-)=(+)$, $(-)\times(+)=(-)$, $(-)^2 = (+)$, $(-)^3 = (-)$.
Core Formula / Rumus Utama
If $x = -4$ and $y = 3$, evaluate: $$E = 3x^2 - 2y$$
Step-by-Step Method:
  1. Always insert negative numbers using safety brackets: $3(-4)^2 - 2(3)$
  2. Apply Index first: $(-4)^2 = 16 \implies 3(16) - 2(3)$
  3. Multiply: $48 - 6 = 42$

Warm-up Exercises / Latihan Pemanasan

1. Evaluate $2x + 7$ when $x = -5$.

Hitung $2x + 7$ saat $x = -5$.

View Step-by-Step Solution / Lihat Solusi

Step 1: Substitute $x = -5 \implies 2(-5) + 7$

Step 2: Multiply: $2 \times (-5) = -10$

Step 3: Add: $-10 + 7 = -3$

Final Answer: $-3$

2. Evaluate $x^2 - 4x$ when $x = -3$.

View Step-by-Step Solution

Step 1: Substitute with brackets: $(-3)^2 - 4(-3)$

Step 2: Evaluate power: $(-3)^2 = 9$

Step 3: Multiply: $-4 \times (-3) = +12$

Step 4: Calculate: $9 + 12 = 21$

Final Answer: $21$

3. Evaluate $\frac{a + b}{c}$ when $a = 12, b = -4, c = 2$.

View Step-by-Step Solution

Step 1: Substitute: $\frac{12 + (-4)}{2}$

Step 2: Simplify numerator: $12 - 4 = 8$

Step 3: Divide: $\frac{8}{2} = 4$

Final Answer: $4$

4. Evaluate $5 - 2p^3$ when $p = -2$.

View Step-by-Step Solution

Step 1: Substitute: $5 - 2(-2)^3$

Step 2: Cube exponent: $(-2)^3 = -8$

Step 3: Multiply: $-2 \times (-8) = +16$

Step 4: Add: $5 + 16 = 21$

Final Answer: $21$

5. True or False: If $x = -3$, then $-x^2 = 9$.

View Step-by-Step Solution

Explanation: $-x^2$ means $-(x^2)$.

Substitute $x = -3 \implies -((-3)^2) = -(9) = -9$.

Therefore, $-x^2 = -9$, NOT $9$. Statement is False!

Final Answer: False

Introduction & Real-World Connection

Pengenalan & Hubungan Dunia Nyata (00:10 - 00:15)

5 min

Why do engineers, doctors, and scientists use algebraic substitution? Formulas represent real-world physical relationships!

Mengapa insinyur, dokter, dan ilmuwan menggunakan substitusi aljabar? Rumus mewakili hubungan fisika di dunia nyata!

  • Temperature Conversion: $F = \frac{9}{5}C + 32$ converts Celsius to Fahrenheit.
  • Kinetic Energy: $E_k = \frac{1}{2}m v^2$ measures energy of a moving car or rocket.
  • Stopping Distance: $d = 0.04 v^2 + 0.2 v$ models braking distance in safety testing.
Visualizing Formulas in Physical Science

Quick Concept Check / Cek Konsep Cepat

Calculate Fahrenheit temperature $F$ when Celsius $C = 30^\circ\text{C}$ using $F = \frac{9}{5}C + 32$.

Show Steps

$F = \frac{9}{5}(30) + 32 = 9 \times 6 + 32 = 54 + 32 = 86^\circ\text{F}$.

Review of Prior Knowledge

In algebraic substitution, terms placed side-by-side imply multiplication.

Side-by-side Variables
$3xy$
Means $3 \times x \times y$
Fractions
$\frac{a + b}{c}$
Implicit brackets: $(a + b) \div c$
Powers vs Coefficients
$-x^2 \neq (-x)^2$
$-3^2 = -9$, whereas $(-3)^2 = +9$
04

Problem Introduction

Pengenalan Masalah Kompleks (00:20 - 00:25)

5 min

Challenge Problem / Masalah Tantangan:

The area $A$ of a trapezium is given by $A = \frac{1}{2}(a + b)h$. Find $A$ when $a = 5.2\text{ cm}, b = 8.8\text{ cm}$, and $h = 4.5\text{ cm}$.

Step-by-step resolution:
  1. Substitute values: $A = \frac{1}{2}(5.2 + 8.8)(4.5)$
  2. Calculate bracket first: $5.2 + 8.8 = 14.0$
  3. Multiply: $A = 0.5 \times 14.0 \times 4.5 = 7 \times 4.5 = 31.5\text{ cm}^2$

Guided Practice

Latihan Terbimbing (00:25 - 00:40)

15 min

Work through these teacher-guided examples step by step. Pay close attention to how negative brackets are handled.

Guided Example 1: Expression with Negatives

Evaluate $3x^2 - y^3$ when $x = -2$ and $y = -3$.

Click for Full Guided Solution

1. Bracket substitution: $3(-2)^2 - (-3)^3$

2. Calculate $(-2)^2 = 4 \implies 3(4) = 12$

3. Calculate $(-3)^3 = -27 \implies 12 - (-27)$

4. Double negative rule: $12 + 27 = 39$

Answer: 39

If $p = 4, q = -2, r = 5$, find the value of $\sqrt{p^2 + q^2 + r}$.

Show Full Solution

$\sqrt{(4)^2 + (-2)^2 + 5} = \sqrt{16 + 4 + 5} = \sqrt{25} = 5$

Answer: 5
